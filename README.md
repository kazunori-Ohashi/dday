# Normandy D-Day Ops

Avalon Hill の `D-Day` そのものの盤面、カウンター、シナリオ文面、表類はコピーしていません。これはノルマンディー上陸作戦を題材にした、オリジナルのデジタル試作です。

## 起動

`index.html` をブラウザで開くと動きます。外部ライブラリやビルド手順はありません。

## 入っているもの

- オリジナルのヘクス盤: 13列 x 10段、海岸、ボカージュ、町、港、河川、湿地、高地
- ユニット: 連合軍、ドイツ軍、歩兵、空挺、機甲、工兵、司令部、守備隊
- シナリオ: `Operation Neptune`, `Omaha Breakout`, `Drive on Caen`
- イベント: 天候、艦砲射撃、海岸混雑、予備解放、空挺攪乱など
- 簡易ルール: 移動範囲表示、隣接戦闘、ステップロス、増援、補給、勝利判定、ドイツ軍AI

## データの差し替え

- 盤面: `data.js` の `terrainOverrides`, `labels`, `controlPoints`
- ユニット: `data.js` の `units`
- シナリオ: `data.js` の `scenarios`
- イベント: `data.js` の `commonEvents`

ゲームの骨格を先に固めるため、戦闘結果表やZOC、スタック、詳細な海上輸送、航空阻止はまだ簡略化しています。
